## Prerequisites

To run this repo successfully, it is recommended with:

- **Linux** (Ubuntu recommended)
- **Python 3.10**
- **Anaconda3**
- **NVIDIA GPU with CUDA support**
- **PyTorch**
- **OpenCV**
- **mamba-ssm**
